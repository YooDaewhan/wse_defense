# 09. 마일스톤과 바이브코딩 티켓

> 각 티켓은 **한 번의 대화로 끝낼 수 있는 크기**로 잘랐다.
> `참고 문서`에 적힌 파일을 컨텍스트로 함께 넣고 작업한다.
> `완료 조건`이 전부 참이 되면 다음 티켓으로 넘어간다.

---

## 사용법

```
프롬프트 템플릿:

  [첨부: 00_OVERVIEW.md, 0X_대상문서.md]

  티켓 T-XX 를 구현해줘.
  - 목표: <티켓의 '목표' 붙여넣기>
  - 산출물: <티켓의 '산출물' 붙여넣기>
  - 완료 조건: <티켓의 '완료 조건' 붙여넣기>

  기존 코드 스타일과 01_ARCHITECTURE.md의 의존 규칙을 반드시 지켜.
  테스트도 함께 작성해줘.
```

**중요한 원칙 3가지**

1. **P0~P1 구간에는 아트를 넣지 않는다.** 색 사각형 플레이스홀더로 전투를 완성한다.
   아트가 없어서 막히는 일이 없어야 한다.
2. **전투 코어(`lib/battle/`)를 먼저, UI를 나중에.** 헤드리스 테스트로 검증 가능한 순서.
3. **Firebase는 Phase 4까지 붙이지 않는다.** 로컬 저장만으로 게임이 완성되게 만든 뒤 연결한다.
