# 08. 제작해야 할 에셋 전체 목록

> 이 문서만 보고 아트·사운드 발주가 가능하도록 작성했다.
> **규격 → 캐릭터 → 적 → 배경 → UI → VFX → 사운드 → 우선순위** 순서.

---

## 1. 공통 규격

### 1.1 해상도 기준

| 항목 | 값 |
|---|---|
| 논리 해상도 (설계 기준) | **1280 × 720** |
| 제작 배율 | **2×** (실제 캔버스 2560 × 1440 기준으로 그린 뒤 아틀라스는 2× 유지) |
| 엔진 스케일 | Flame `CameraComponent.withFixedResolution(1280, 720)` |
| 최소 지원 기기 | 720p, RAM 3GB |
| 색공간 | sRGB, PNG-32 (알파 포함) |

### 1.2 캐릭터 스프라이트 크기 (2× 제작 기준, 괄호는 논리 크기)

| 체급 | 프레임 캔버스 | 실제 캐릭터 높이 | 해당 |
|---|---|---|---|
| XS 자그마함 | 128 × 128 (64×64) | 약 90px (45) | 도토리, 작은 벌레 |
| S 소동물 | 160 × 160 (80×80) | 약 120px (60) | 물방울, 새, 다람쥐 |
| M 보통 | 224 × 224 (112×112) | 약 170px (85) | 버섯, 늑대, 소녀 |
| L 커다람 | 320 × 320 (160×160) | 약 250px (125) | 곰, 거북 |
| BOSS | 512 × 512 (256×256) | 약 420px (210) | 숲의 큰곰 등 |

- **모든 프레임은 같은 캔버스 크기.** 프레임마다 캔버스가 다르면 흔들린다.
- **앵커(pivot)는 캔버스 하단 중앙** (`anchor: Anchor.bottomCenter`).
  발이 땅에 닿는 지점을 캔버스 맨 아래에서 위로 **4px(2× 기준 8px)** 띄운다 (그림자 여유).
- 방향은 **우향만 제작.** 적은 엔진에서 좌우 반전.
  단 글자·비대칭 장식이 있으면 별도 좌향 시트 필요 → 발주서에 명시.

### 1.3 파일·폴더 네이밍

```
assets/images/
├─ characters/
│  └─ chr_acorn/
│     ├─ chr_acorn.png          # 아틀라스 (한 장)
│     ├─ chr_acorn.json         # 아틀라스 메타 (프레임 좌표)
│     └─ src/                   # 원본 레이어 파일 (aseprite/psd), 빌드 제외
├─ enemies/
│  └─ enm_squirrel/...
├─ backgrounds/
│  └─ bg_forest_entrance/
│     ├─ bg_forest_entrance_l0_sky.png
│     ├─ bg_forest_entrance_l1_far.png
│     ├─ bg_forest_entrance_l2_mid.png
│     └─ bg_forest_entrance_l3_ground.png
├─ ui/
│  ├─ common/
│  ├─ tags/
│  ├─ equipments/
│  ├─ items/
│  └─ portraits/
├─ vfx/
└─ illust/                      # 프롤로그·스토리 일러스트
```

- 파일명 소문자 + 언더스코어. 공백·한글·대문자 금지.
- 아틀라스 이름은 `characters.json`의 `art.atlasKey` 와 정확히 일치해야 한다.

### 1.4 아틀라스 규칙

- 캐릭터 1종 = **아틀라스 1장.** 여러 캐릭터를 한 장에 몰지 않는다 (필요한 것만 로드).
- 최대 크기 **2048 × 2048.** 초과하면 프레임 수를 줄이거나 2장으로 분할.
- 패딩 2px, extrude 1px (인접 프레임 색 번짐 방지).
- UI 아이콘은 종류별로 묶어 아틀라스 1장 (`ui_tags.png`, `ui_items.png`, ...).

### 1.5 아트 방향 (기획서 §5)

| 항목 | 지침 |
|---|---|
| 팔레트 | 연두 `#9DC183` / 크림 `#F2E8D5` / 살구 `#EFB08C` / 갈색 `#C08A4A` 중심 |
| 실루엣 | 둥근 형태. 날카로운 각 최소화 |
| 그림자 | 부드러운 타원 그림자 (별도 스프라이트, 캐릭터와 분리) |
| 라인 | 얇은 갈색 외곽선 (`#7A5C3E`, 2× 기준 3px) 또는 라인 없음 — **작품 내에서 통일** |
| 역할 구분 | 방어형=둥글고 넓음 / 공격형=가늘고 뾰족 / 지원형=부드럽고 장식 / 교란형=작고 날렵 |
| 패배 연출 | 굴러가거나 달아나는 형태. 피·훼손 표현 금지 |
| 밤 상태 | 색을 어둡게 하지 않고 **포근한 남색 톤**으로 이동. 대비 유지 |

## 2. 캐릭터 애니메이션 클립 (★ 요청하신 이동·피격·죽음 포함)

### 2.1 필수 클립 7종

| 클립 | 프레임 | FPS | 루프 | 내용 |
|---|---:|---:|---|---|
| `idle` | 4 | 8 | O | 대기. 숨쉬기·살짝 흔들림 |
| **`move`** | 6 | 12 | O | **이동.** 걷기/구르기/날갯짓 등 캐릭터별 이동 방식 |
| `attack` | 8 | — | X | 공격. **3분할 필수** (§2.2) |
| **`hit`** | 3 | 20 | X | **피격.** 몸이 뒤로 살짝 젖혀지고 눈이 감김 |
| `knockback` | 4 | 12 | X | 밀려남. 뒤로 미끄러지며 균형 잃음 |
| **`death`** | 6 | 12 | X | **죽음.** 마지막 프레임은 알파 0에 가깝게 |
| `spawn` | 5 | 15 | X | 소환 등장. 빛에서 나타나는 느낌 |

**합계 36프레임** (필수). 아틀라스 1장에 여유 있게 들어간다.

### 2.2 `attack` 클립 3분할 (가장 중요)

```
프레임:  1    2    3   │  4  │  5    6    7    8
        ├─ windup ────┤ 판정 ├──── recover ────┤
         (준비 동작)   (타격)   (되돌아오는 동작)

characters.json 에 반드시 명시:
  "attack": { "frames": 8, "windupFrames": 3, "impactFrame": 4, "recoverFrames": 4 }
```

엔진이 캐릭터의 `attackWindup(A)` / `attackRecover(R)` 틱에 맞춰 각 구간을
시간 스케일하므로, **애니메이터는 프레임 수만 맞추면 된다.**

| 캐릭터 | A (틱) | R (틱) | windup 프레임당 | recover 프레임당 |
|---|---:|---:|---|---|
| 도토리 | 12 | 48 | 4틱 (0.13초) | 12틱 (0.4초) |
| 물방울 | 18 | 72 | 6틱 (0.2초) | 18틱 (0.6초) |
| 곰 | 36 | 69 | 12틱 (0.4초) | 17틱 (0.57초) |

→ **곰처럼 A가 긴 캐릭터는 windup을 4~5프레임으로 늘려도 좋다** (느린 준비 동작이 예고가 됨).
곰 발주 시: `windupFrames: 5, impactFrame: 6, recoverFrames: 4` (총 10프레임).

### 2.3 선택 클립 (있으면 좋음, 없으면 대체)

| 클립 | 프레임 | 대체 처리 |
|---|---:|---|
| `stun` | 3 | 없으면 `idle` + 노란 별 아이콘 |
| `skill` | 6~8 | 없으면 `attack` 재사용 |
| `victory` | 4 | 없으면 `idle` |
| `heal_cast` | 5 | 지원형만. 없으면 `attack` |

### 2.4 피격 처리 원칙 (구현 메모, 애니메이터 참고)

- 피격은 **클립을 강제로 바꾸지 않는다.** 공격 모션 중에 `hit`으로 갈아타면 판정 타이밍이 깨진다.
- 공격 중 피격 → 흰색 틴트 0.08초 + 3px 셰이크만.
- `idle`/`move` 중 피격 → `hit` 클립 1회 재생 후 원래 클립 복귀.
- 따라서 `hit`은 **짧고(3프레임) 원래 자세로 돌아오는** 형태로 만들어야 한다.

## 4. 배경 (★ 요청하신 배경화면)

### 4.1 전투 배경 구조 — 4레이어 파랄랙스

```
l0_sky      2048 × 720   (2× 제작: 4096 × 1440)  스크롤 계수 0.05  ─ 하늘, 구름
l1_far      3072 × 720                            스크롤 계수 0.25  ─ 먼 나무, 산
l2_mid      3072 × 720                            스크롤 계수 0.55  ─ 중간 나무, 덤불
l3_ground   3072 × 400   (하단 정렬)               스크롤 계수 1.00  ─ 바닥, 길, 풀
```

- **가로 타일링 가능하게** 좌우 끝이 이어져야 한다 (seamless).
- 전장 길이 2400 논리 단위 = 화면 1600 논리 단위가 보이므로,
  카메라 이동 범위는 800 논리 단위. `l3_ground`는 3072px면 충분.
- `l0_sky` 는 날씨 상태별 **3종** 필요: `_clear`, `_dusk`, `_night`.
  나머지 레이어는 엔진에서 컬러 틴트로 처리 (제작비 절감).

### 4.2 챕터 1 배경 10종 (기획서 §8)

| 스테이지 | 배경 ID | 분위기 |
|---|---|---|
| 1-1 | `bg_forest_entrance` | 햇살 숲 입구. 나뭇잎 사이 빛 |
| 1-2 | `bg_petal_path` | 꽃잎 오솔길. 분홍 꽃잎 |
| 1-3 | `bg_mushroom_rest` | 버섯 쉼터. 큰 버섯들 |
| 1-4 | `bg_acorn_hill` | 도토리 언덕. 완만한 경사 |
| 1-5 | `bg_small_bridge` | 작은 다리. 나무 다리 |
| 1-6 | `bg_babbling_brook` | 졸졸 개울. 물가 |
| 1-7 | `bg_berry_road` | 산딸기 길. 붉은 열매 |
| 1-8 | `bg_windy_hill` | 바람 언덕. 풀이 눕는 |
| 1-9 | `bg_forest_clearing` | 숲속 공터. 넓은 하늘 |
| 1-10 | `bg_big_tree` | 커다란 나무 앞. 보스전 |

> `bg_forest_entrance` 를 **베이스 세트**로 만들고, `l1_far`/`l2_mid`는 공유하면서
> `l3_ground` 와 **전경 장식 오브젝트 3~5개**만 교체해 변화를 준다.
> 실제 신규 제작은 **베이스 3종**(숲 / 물가 / 언덕) + **장식 오브젝트 20종** 이면 충분.

### 11.1 Aseprite 사용 시 내보내기 커맨드

```bash
aseprite -b chr_acorn.aseprite \
  --sheet-type packed --sheet-pack \
  --sheet chr_acorn.png \
  --data chr_acorn.json \
  --format json-hash \
  --list-tags --list-layers \
  --shape-padding 2 --border-padding 2 --inner-padding 1
```

태그(클립) 이름은 반드시 `idle` / `move` / `attack` / `hit` / `knockback` / `death` / `spawn`
으로 지정한다. `attack` 태그 안에 `attack_windup` / `attack_impact` / `attack_recover`
서브 태그를 두면 로더가 3분할 정보를 자동으로 읽는다.
