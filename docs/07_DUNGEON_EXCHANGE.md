# 07. 요일던전 · 조각 · 교환소

> 기획서의 "소풍"을 **요일던전(dailyDungeon)** 으로 확정하고, 난이도를 5단계로,
> 보상을 **조각(shard) 수집 → 10개 교환** 구조로 정의한다.
> 이 콘텐츠가 태그 시스템의 파밍 동기를 만든다: **장비가 태그를 열어준다.**

---

## 1. 구조 요약

```
요일던전 3종 × 난이도 5단계
        │
        ├─ 드랍: 골드 + 조각(T1/T2/T3) + 친밀도·꾸미기 재료
        │
        ├─ T1·T2 조각 → 장비 강화 재료 / 승급 재료
        │
        └─ T3 조각 10개 → 교환소에서 장비 1종 선택 획득
                              │
                              └─ 그 장비가 태그를 부여 → 팀 태그 레벨 상승
                                    → 새 시너지 티어 진입 → 새 편성이 성립
```

**일일 입장 횟수 6회를 3종이 공유한다** (기획서 유지). 소탕도 횟수를 소비한다.
한 번 클리어한 난이도는 무료 소탕 가능.

## 2. 던전 3종

| ID | 이름 | 기질 테마 | 조각 계열 | 요일 보너스 |
|---|---|---|---|---|
| `DGN_SUN` | 햇살 놀이터 | 해 | `ITM_SHARD_SUN_T1/T2/T3` | 월, 목 |
| `DGN_MOON` | 달빛 쉼터 | 달 | `ITM_SHARD_MOON_T1/T2/T3` | 화, 금 |
| `DGN_FIELD` | 들꽃 언덕 | 들 | `ITM_SHARD_FIELD_T1/T2/T3` | 수, 토 |

**일요일은 3종 모두 보너스 적용.** 기본 보상은 모든 요일에 접근 가능(요일 제한 없음).

### 2.1 던전별 성격 (기믹으로 차별화)

| 던전 | 등장 적 성향 | 대응 축 |
|---|---|---|
| `DGN_SUN` | 빠르고 많은 적. 물량 압박 | 범위 공격, 저비용 벽 |
| `DGN_MOON` | 원거리·회복 보유 적. 지속전 | 사거리, 교란(멈칫/느릿) |
| `DGN_FIELD` | 고HP 소수 + 넉백 저항 | 단일 고DPS, 관통 |

> 세 던전이 요구하는 편성이 달라야 파밍이 지루해지지 않는다.
> 각 던전이 **자기 계열 장비를 요구하지 않도록** 한다 (해 던전에 해 장비만 필요 → 순환 잠김).

## 3. 난이도 5단계

| 난이도 | 이름 | 해금 조건 | 권장 동행Lv | 적 기지 HP | 제한시간 | 목표 클리어 |
|---|---|---|---:|---:|---:|---|
| 1 | 산책 | 챕터1-3 클리어 | 8 | 6,000 | 120초 | 50~70초 |
| 2 | 나들이 | 난이도1 클리어 | 16 | 12,000 | 150초 | 70~90초 |
| 3 | 소풍 | 난이도2 클리어 + 챕터1 클리어 | 26 | 24,000 | 180초 | 90~120초 |
| 4 | 먼 길 | 난이도3 클리어 + 챕터2 클리어 | 38 | 42,000 | 210초 | 110~140초 |
| 5 | 깊은 오후 | 난이도4 클리어 + 챕터3 클리어 | 52 | 70,000 | 240초 | 130~170초 |

- 난이도 3부터 **스테이지 기믹 1개**를 붙인다 (날씨 편향 / 편성 제한 / 필살기 봉인 중 하나).
- 난이도 5에는 **미니 보스 1체**를 둔다 (챕터 보스 재활용 + 수치 강화).
- `minClearSec` = 목표 클리어 하한의 절반 (서버 검증용).

### 3.2 요일 보너스 규칙

```
보너스 요일에는:
  · 골드 드랍 +50%
  · T1/T2 조각 드랍 +50% (내림)
  · T3 조각 +1개 확정 (난이도 5)
  · 보너스 표시를 던전 목록에 항상 노출
```

**보너스 요일이 아니어도 입장·클리어·기본 보상은 모두 가능하다.**
요일 제한으로 플레이를 막지 않는다 (기획서 원칙 유지).

## 4. 조각(Shard) 드랍표

### 4.1 티어별 용도 — 이게 설계의 핵심

| 티어 | 주 용도 | 부 용도 |
|---|---|---|
| **T1** | 장비 강화 (+1 ~ +5) | 5개 → T2 1개 승급 |
| **T2** | 장비 강화 (+6 ~ +10) | 5개 → T3 1개 승급 |
| **T3** | **장비 교환 (10개 = 장비 1종)** | — |

> T1/T2는 "쓰는" 재화, T3는 "모으는" 재화로 분리한다.
> 그러면 강화를 하느라 교환이 늦어지는 갈등이 생기지 않고,
> 동시에 T1/T2가 남으면 승급으로 T3를 만들 수 있어 사장되지 않는다.

### 4.2 난이도별 조각 드랍 (한 판 기준, 보너스 요일 아님)

| 난이도 | T1 | T2 | T3 | 골드 |
|---:|---|---|---|---:|
| 1 | 3~4 | — | — | 800~1,200 |
| 2 | 5~6 | — | — | 1,400~2,000 |
| 3 | 6~8 | 1~2 | — | 2,400~3,200 |
| 4 | 4~6 | 3~4 | — | 3,600~4,800 |
| 5 | — | 4~6 | **1** | 5,000~7,000 |

보너스 요일: 위 값 ×1.5 (내림) + 난이도 5에서 T3 **+1**

### 4.3 수급 시뮬레이션

한 종류 던전 난이도 5에 하루 6회를 전부 투입할 경우:

| 상황 | 하루 T3 | 10개 교환까지 |
|---|---:|---|
| 일반 요일 | 6 | 약 1.7일 |
| 보너스 요일 | 12 | 약 0.8일 |
| 3종 균등 분배 (2회씩) | 각 2 | 각 5일 |

**장비 교환 1종당 1~2일**이 기본 페이스. 초기 장비 목록 18종이므로
전부 모으려면 약 1개월. 강화(+10)까지 고려하면 T1/T2 소비가 계속 필요하다.

> 이 페이스가 너무 빠르면 `T3 필요 개수`를 10 → 15로 올리거나,
> 난이도 5의 T3 드랍을 확정 1개 → 70% 확률로 조정한다.
> **드랍표만 수정하면 되도록** `dungeons.json`에서 관리한다.

## 5. 교환소 (Exchange)

### 5.1 화면 구성

```
/exchange

[해 조각] [달 조각] [들 조각] [이벤트]        ← 상단 탭

보유:  🌞T1 124   🌞T2 38   🌞T3 7
                                     ┌───────────────────────┐
┌──────────────┐ ┌──────────────┐   │ 🌞T3 ×5 → 🌞T3... 아님 │
│  동물탈       │ │  용감의 뱃지  │   │ 승급                   │
│ 🐾동물 Lv+1   │ │ 💪용감 Lv+1   │   │ 🌞T1×5 → 🌞T2×1  [교환]│
│ 최대체력 +4%  │ │ 공격력 +6%    │   │ 🌞T2×5 → 🌞T3×1  [교환]│
│ 🌞T3 ×10      │ │ 🌞T3 ×10      │   └───────────────────────┘
│   [교환]      │ │   [교환]      │
└──────────────┘ └──────────────┘
```

각 장비 카드에는 **부여 태그를 가장 크게** 표시한다. 옵션 수치보다 태그가 중요하기 때문.
카드 탭 시 "이 장비를 장착하면 팀 동물 레벨이 4 → 5가 됩니다. 동물 Lv6 티어까지 1 남았습니다."
같은 **현재 편성 기준 안내**를 띄운다.

### 5.2 exchange.json

```jsonc
{
  "upgrades": [
    { "id": "UPG_SUN_T1_T2", "cost": [{"item":"ITM_SHARD_SUN_T1","amount":5}],
      "gain": {"type":"ITEM","id":"ITM_SHARD_SUN_T2","amount":1}, "limit": 0 },
    { "id": "UPG_SUN_T2_T3", "cost": [{"item":"ITM_SHARD_SUN_T2","amount":5}],
      "gain": {"type":"ITEM","id":"ITM_SHARD_SUN_T3","amount":1}, "limit": 0 }
  ],
  "shops": [
    {
      "id": "SHOP_DUNGEON_SUN",
      "nameKey": "shop.dungeon.sun",
      "entries": [
        { "id": "EX_SUN_ANIMAL_MASK",
          "cost": [{"item":"ITM_SHARD_SUN_T3","amount":10}],
          "gain": {"type":"EQUIPMENT","id":"EQP_ANIMAL_MASK"},
          "limit": 0, "resetPeriod": "NONE",
          "unlock": {"difficultyCleared":{"dungeonId":"DGN_SUN","level":4}} },
        { "id": "EX_SUN_BRAVE_BADGE",
          "cost": [{"item":"ITM_SHARD_SUN_T3","amount":10}],
          "gain": {"type":"EQUIPMENT","id":"EQP_BRAVE_BADGE"},
          "limit": 0, "resetPeriod": "NONE" },
        { "id": "EX_SUN_GOLD_POUCH",
          "cost": [{"item":"ITM_SHARD_SUN_T1","amount":20}],
          "gain": {"type":"CURRENCY","id":"ITM_GOLD","amount":6000},
          "limit": 5, "resetPeriod": "WEEKLY" }
      ]
    }
  ]
}
```

| 필드 | 설명 |
|---|---|
| `limit` | 0 = 무제한, n = 기간 내 n회 |
| `resetPeriod` | `NONE` / `DAILY` / `WEEKLY` / `EVENT` |
| `unlock` | 노출 조건 (난이도 클리어, 챕터 클리어 등) |

**서버 검증:** `exchangeItems` 함수는 클라이언트가 보낸 cost/gain을 신뢰하지 않고
서버 사본에서 entry를 조회해 처리한다 (`06_BACKEND.md §4.6`).

## 6. 장비 목록 (초기 18종)

> 기획서의 "고정 옵션 12종"을 태그 부여 장비 6종 + 순수 옵션 12종 = 18종으로 확장.
> 태그 부여 장비는 **T3 조각 10개**, 순수 옵션 장비는 T2/T1 조각으로 교환한다.

### 6.1 태그 부여 장비 (T3 ×10) — 파밍의 목표

| ID | 이름 | 부여 태그 | 고정 옵션 | 던전 | +5 추가 |

| `EQP_ANIMAL_MASK` | 동물탈 | `TAG_RACE_ANIMAL +1` | 최대체력 +4% | 해 | 동물 +1 |
| `EQP_LEAF_CLOAK` | 잎사귀 망토 | `TAG_RACE_PLANT +1` | 최대체력 +6% | 들 | 식물 +1 |
| `EQP_EMBER_CHARM` | 불씨 부적 | `TAG_ELEM_FIRE +1` | 공격력 +5% | 해 | 불 +1 |
| `EQP_DEWDROP_BELL` | 이슬 방울 | `TAG_ELEM_WATER +1` | 공격력 +5% | 달 | 물 +1 |
| `EQP_BRAVE_BADGE` | 용감의 뱃지 | `TAG_TRAIT_BRAVE +1` | 공격력 +6% | 해 | 용감 +1 |
| `EQP_HIDING_HOOD` | 숨는 두건 | `TAG_TRAIT_COWARD +1` | 소환비용 −10% | 달 | 겁쟁이 +1 |

> `EQP_HIDING_HOOD` 가 겁쟁이를 **일부러 부여**하는 장비인 이유:

### 6.3 강화

| 항목 | 규칙 |
|---|---|
| 최대 | +10 |
| 실패 | 없음 (기획서 유지) |
| 비용 | +1~+5: `T1 조각 × (3 + level×2)` + 골드 / +6~+10: `T2 조각 × (2 + level)` + 골드 |
| 효과 | 고정 옵션이 단계별 가산. 태그 부여 장비는 **+5에서 태그 +1** |
| 해제·교체 | 무료 (기획서 유지) |
| 이관 | 다른 캐릭터에 옮겨도 강화 단계 유지 |

**+5 태그 추가는 UI에 반드시 사전 표시한다.** "+5 도달 시 동물 Lv+1" 이 강화 동기다.

## 7. 태그 시스템과의 연결 (설계 의도)

```
요일던전을 도는 이유
  = 조각을 모아 장비를 얻는 것
  = 팀 태그 레벨을 올리는 것
  = 새로운 시너지 티어를 여는 것
  = 이전에 불가능했던 편성이 성립하는 것
```

### 7.1 진행 곡선 예시

| 시점 | 팀 동물 Lv | 상태 |
|---|---:|---|
| 챕터1 클리어 | 2 | 동물 캐릭터 2명뿐. 시너지 없음 |
| 동물 캐릭터 1명 추가 획득 | 3 | **Lv3 티어 진입** — 공/방 +2% |
| 동물탈 1개 교환·장착 | 4 | 티어 유지, Lv6까지 2 남음 (UI가 알려줌) |
| 동물탈 +5 강화 | 5 | Lv6까지 1 남음 |
| 잎사귀 망토가 아니라 두 번째 동물탈 교환 | 6 | **Lv6 티어 진입** — 공/방 +5% |

플레이어는 "동물 캐릭터를 더 뽑을까, 동물탈을 더 모을까, 강화할까"를 고민한다.
**세 경로가 같은 목표로 수렴하는 것**이 좋은 성장 설계다.

### 7.2 밸런스 가드레일

- 태그 티어 효과는 **한 티어당 최대 +5%** 수준으로 유지. 티어 하나가 전투를 결정하면
  단일 정답 편성이 생긴다.
- 한 장비가 부여하는 태그는 **최대 1종 1레벨** (+5 강화 시 +1 추가까지).
- 팀 태그 최대 레벨 `maxTeamLevel`을 20으로 잡되, **실제 티어는 Lv10까지만 정의**한다.
  상한 여유를 남겨야 나중에 티어를 추가할 수 있다.
- 서로 배타적인 태그(겁쟁이/용감)를 한 유닛에 몰아 무한 강화하는 조합이 생기지 않게
  `conflicts` 규칙을 반드시 넣는다 (`02_TAG_SYSTEM.md §6.6`).

## 8. 깊은 숲 (deepForest) 연동

| 항목 | 규칙 |
|---|---|
| 입장 | 상시, 횟수 무제한 |
| 구조 | 층 단위 진행. 최고 클리어 층 기록 유지 |
| 주간 초기화 | **보상 수령 상태만** 초기화. 클리어 기록은 유지 |
| 보상 | `T2/T3 조각` + `장비 강화 재료` + 단계 보상 |
| 이미 정복한 층 | 일괄 보상 수령 후 미클리어 층 도전 |
| 태그 연계 | **층마다 편성 제한 태그가 다르다** (예: 12층 = 동물 태그 3 이상 필수) |

> 깊은 숲의 태그 제한이 "요일던전에서 얻은 장비로 태그를 채워 층을 뚫는" 순환을 만든다.
> 요일던전(재화 수급) → 교환소(장비) → 깊은 숲(태그 제한 돌파) → 더 좋은 재화.

---

## 9. 일일 흐름 (기획서 §8 유지)

```
정비·보상 확인          1~2분
요일던전 6회 (소탕 포함)  1~3분
모험 또는 이벤트 2~3판    5~10분
────────────────────────────
합계                    약 10~15분
```

- 일일 미션 3개, 접속·전투·성장 행동에 **대체 조건** 제공. 구매를 완료 조건으로 요구하지 않음.
- 소탕은 1탭으로 6회 일괄 처리 가능 (`sweepDungeon(times: 6)`).
- 소탕 결과는 획득 아이템 요약 + "교환소에 새로 교환 가능한 것이 있습니다" 배지.

## 10. 구현 체크리스트

- [ ] `dungeons.json` / `items.json` / `exchange.json` 로딩 및 검증
- [ ] 요일 계산은 **서버 시각 기준** (`serverState/schedule.dailyResetHourUtc`)
      → 클라이언트 로컬 시각으로 요일 보너스를 판단하지 않는다 (시각 조작 방지)
- [ ] 일일 잔여 횟수는 `dailyCounters/{yyyy-MM-dd}` 문서로 관리, TTL 자동 삭제
- [ ] 드랍 추첨은 **서버에서만** (`submitBattle` / `sweepDungeon`)
- [ ] 소탕 자격: 해당 난이도 1회 이상 클리어 기록 확인
- [ ] 교환 시 `limit`/`resetPeriod` 검증, 멱등키 적용
- [ ] 강화 재료 소비와 단계 상승을 하나의 트랜잭션으로
- [ ] 장비 장착/해제 시 팀 태그 프리뷰 즉시 갱신 (클라이언트 로컬 계산)
- [ ] `+5 태그 추가` 도달 시 축하 연출 + 팀 태그 변화 하이라이트
- [ ] 교환 가능 항목이 새로 생기면 캠프 하단 탭에 배지
- [ ] 지표: `dungeon_run`, `exchange_used`, `tag_tier_activated` 로 실제 순환이 도는지 확인
